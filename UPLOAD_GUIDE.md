## ⏱️ After Upload (Enable GitHub Pages)

Once files are uploaded:

1. Go to **Settings** tab (top of repository page)
2. Click **"Pages"** in left sidebar
3. Under "Branch": Select **`main`**
4. Under "Folder": Select **`/ (root)`**
5. Click **"Save"**
6. Wait 2 minutes

## 🆘 If Something Goes Wrong

**Files not uploading?**
- Try uploading in batches (HTML files first, then assets folder)

**404 Error on live site?**
- Make sure `index.html` is in the root, not in a subfolder
- Wait 5 minutes for GitHub to process

**CSS not loading?**
- All paths are relative, should work automatically
- Clear browser cache (Ctrl+Shift+R)
