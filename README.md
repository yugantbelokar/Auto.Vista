# AutoVista - Automobile Marketplace

**See Every Ride Clearly** - India's leading automobile marketplace for Cars & Bikes.

## 🚀 Features

- **Homepage** with premium hero section and search
- **Cars & Bikes Listings** with filterable grids
- **Vehicle Detail Pages** with specs and pricing
- **Responsive Design** - Mobile-first approach
- **Modern UI** - Clean white background with red accents

## 🛠️ Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, CSS Variables)
- Vanilla JavaScript
- Feather Icons

## 🌐 How to Run Locally

Simply open `index.html` in your browser. No build process or server required!

## 🚀 Deployment Options

### Option 1: GitHub Pages (Recommended)
1. Create a GitHub repository
2. Push this project to the repository
3. Go to Settings → Pages
4. Select branch `main` and folder `/root`
5. Your site will be live at `https://yourusername.github.io/autovista`

### Option 2: Netlify
1. Visit [netlify.com](https://netlify.com)
2. Drag and drop the `autovista` folder
3. Your site will be live instantly!

### Option 3: Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project directory
3. Follow the prompts
